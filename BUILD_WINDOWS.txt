Windows-EXE selbst bauen (einmalig, auf einem echten Windows-Rechner)
======================================================================

Abkuerzung: build_exe.ps1 (im selben Ordner) automatisiert alle Schritte
unten - prueft Python, installiert PyInstaller, laedt rclone.exe bei Bedarf
automatisch herunter und startet den Build. Einfach in PowerShell ausfuehren:

     .\build_exe.ps1

Falls PowerShell die Ausfuehrung von Skripten blockiert ("... is not digitally
signed"), einmalig erlauben:

     Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Manueller Nachbau (nur falls build_exe.ps1 wirklich nicht nutzbar ist):

Warum: PyInstaller baut nur fuer das Betriebssystem, auf dem es laeuft - eine
echte Windows-.exe kann nicht von diesem Mac aus gebaut werden. Die macOS-
Variante (dist/onedrive-sharepoint-migration-tool.app) ist bereits fertig und
enthaelt Python + rclone eingebettet - keine separate Installation mehr noetig.

Seit dem Umstieg auf ein Icon + Splash-Screen (siehe onedrive-sharepoint-
migration-tool.spec) reicht ein einzelner "pyinstaller <flags> script.py"-
Aufruf nicht mehr aus - Icon/Splash/console=False lassen sich nur ueber die
.spec-Datei konfigurieren. Der manuelle Nachbau besteht deshalb nur noch aus:

1. Python installieren (falls noch nicht vorhanden):
   https://www.python.org/downloads/ -> beim Installer "Add python.exe to PATH" anhaken.

2. PowerShell oder cmd oeffnen, in den Projektordner wechseln, dann:

     pip install pyinstaller customtkinter

3. Aktuelle rclone-Windows-Version herunterladen und entpacken:
   https://rclone.org/downloads/ -> "Windows / amd64" -> zip entpacken,
   rclone.exe in den GLEICHEN Ordner wie onedrive-sharepoint-migration-tool.py legen.

4. Build ueber die mitgelieferte .spec-Datei starten (ueber "python -m
   PyInstaller" statt nur "pyinstaller" - sonst kommt oft "'pyinstaller' is
   not recognized", weil pip das Kommando in einen Ordner installiert, der
   nicht automatisch im PATH liegt):

     python -m PyInstaller --noconfirm onedrive-sharepoint-migration-tool.spec

   Falls "python" ebenfalls nicht gefunden wird, stattdessen "py -m PyInstaller ...".

   Ergebnis liegt danach in: dist\onedrive-sharepoint-migration-tool.exe
   (einzelne Datei, Python + rclone bereits eingebettet, ca. 40-50 MB).
   Enthaelt BEIDE Werkzeuge (Kopieren/Migrieren als GUI direkt, Duplikate
   finden + Terminal-Oberflaeche fuer beide ueber --cli).

5. dist\onedrive-sharepoint-migration-tool.exe in den gewuenschten Zielordner
   kopieren (gleicher Ordner wie onedrive-sharepoint-migration-tool.bat).

Danach genuegt ein Doppelklick auf die .bat (oder direkt auf die .exe) - ohne
vorherige Python- oder rclone-Installation auf dem Zielrechner. Die .bat prueft
selbst, ob die .exe im gleichen Ordner liegt, und nutzt sie automatisch.

Hinweis zu SmartScreen/Antivirus: Eine unsignierte, frisch gebaute .exe wird
von Windows SmartScreen beim ersten Start oft als "unbekannter Herausgeber"
gemeldet. Ueber "Weitere Informationen" -> "Trotzdem ausfuehren" bestaetigen.
Das laesst sich nur durch ein kostenpflichtiges Code-Signing-Zertifikat
vermeiden - fuer ein persoenliches Tool in der Regel nicht notwendig.
