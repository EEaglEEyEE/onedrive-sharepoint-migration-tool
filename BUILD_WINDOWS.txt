Windows-EXE selbst bauen (einmalig, auf einem echten Windows-Rechner)
======================================================================

Warum: PyInstaller baut nur fuer das Betriebssystem, auf dem es laeuft - eine
echte Windows-.exe kann nicht von diesem Mac aus gebaut werden. Die macOS-
Variante (onedrive-sharepoint-migration-tool, ohne Dateiendung) ist bereits
fertig und enthaelt Python + rclone eingebettet - keine separate Installation
mehr noetig.

Schritte auf einem Windows-Rechner:

1. Python installieren (falls noch nicht vorhanden):
   https://www.python.org/downloads/ -> beim Installer "Add python.exe to PATH" anhaken.

2. PowerShell oder cmd oeffnen, in den Ordner mit onedrive-sharepoint-migration-tool.py
   wechseln, dann:

     pip install pyinstaller

3. Aktuelle rclone-Windows-Version herunterladen und entpacken:
   https://rclone.org/downloads/ -> "Windows / amd64" -> zip entpacken,
   rclone.exe in den GLEICHEN Ordner wie onedrive-sharepoint-migration-tool.py legen.

4. Build starten (Windows nutzt ";" statt ":" bei --add-binary!). Ueber
   "python -m PyInstaller" statt nur "pyinstaller" aufrufen - sonst kommt oft
   "'pyinstaller' is not recognized", weil pip das Kommando in einen Ordner
   installiert, der nicht automatisch im PATH liegt (z.B. .../Scripts):

     python -m PyInstaller --onefile --console --name onedrive-sharepoint-migration-tool --add-binary "rclone.exe;." onedrive-sharepoint-migration-tool.py

   Falls "python" ebenfalls nicht gefunden wird, stattdessen "py -m PyInstaller ...".

   Ergebnis liegt danach in: dist\onedrive-sharepoint-migration-tool.exe
   (einzelne Datei, Python + rclone bereits eingebettet, ca. 30-40 MB)

5. dist\onedrive-sharepoint-migration-tool.exe in den gewuenschten Zielordner
   kopieren (gleicher Ordner wie onedrive-sharepoint-migration-tool.bat).

Danach genuegt ein Doppelklick auf die .bat (oder direkt auf die .exe) - ohne
vorherige Python- oder rclone-Installation auf dem Zielrechner. Die .bat prueft
selbst, ob die .exe im gleichen Ordner liegt, und nutzt sie automatisch.

Hinweis zu SmartScreen/Antivirus: Eine unsignierte, frisch gebaute .exe wird
von Windows SmartScreen beim ersten Start oft als "unbekannter Herausgeber"
gemeldet. Ueber "Weitere Informationen" -> "Trotzdem ausfuehren" bestaetigen.
Das laesst sich nur durch ein kostenpflichtiges Code-Signing-Zertifikat
vermeiden - fuer ein persoenliches Tool in der Regel nicht notwendig.


Zweites Tool: onedrive_dedupe_report (Duplikat-Finder)
======================================================================

Gleiches Vorgehen wie oben, nur mit anderem Skriptnamen (Schritte 1-3 identisch,
gleicher rclone.exe-Ordner kann wiederverwendet werden):

     python -m PyInstaller --onefile --console --name onedrive_dedupe_report --add-binary "rclone.exe;." onedrive_dedupe_report.py

Ergebnis: dist\onedrive_dedupe_report.exe (Python + rclone eingebettet).

Dieses Tool braucht immer Parameter (--remote, --output, ...) und ist daher
bewusst ohne Doppelklick-Starter/.bat gedacht - einfach direkt aus einer
Konsole aufrufen:

     onedrive_dedupe_report.exe --remote onedrive: --output report.csv
